# Offline penuh

Game berjalan sepenuhnya tanpa koneksi internet: tidak ada akun, leaderboard, cloud save, maupun iklan jaringan. Semua progres disimpan lokal di perangkat. Fitur online yang ada di game aslinya sengaja tidak disalin.

## Consequences

- Arsitektur menyiapkan mekanisme kunci level, yang dipakai untuk urutan progres antar-level. Monetisasi bukan pertimbangan desain (lihat ADR 0007).
- Kehilangan data save (uninstall, ganti HP) tidak bisa dipulihkan dari server.
