# Penggunaan pribadi: lisensi aset bebas, tetapi tercatat

Game ini dibuat sebagai hobi untuk dimainkan sendiri dan kemungkinan besar tidak akan dikomersialkan. Karena itu aset dengan lisensi apa pun boleh dipakai, termasuk CC-BY-NC, CC-BY-ND, dan GPL, yang biasanya dihindari untuk produk komersial. Game didistribusikan sebagai APK yang di-sideload, bukan lewat Google Play, sehingga ukuran APK boleh sampai 1 GB.

## Consequences

- Setiap aset pihak ketiga tetap dicatat di `CREDITS.md` (nama file, sumber, URL, pembuat, lisensi) dan ditampilkan di menu Credits. Kalau suatu saat game dirilis publik, aset NC/ND/GPL bisa langsung ditemukan dan diganti.
- Mekanisme kunci level dari ADR 0003 tetap ada, tetapi monetisasi tidak lagi menjadi pertimbangan desain.
